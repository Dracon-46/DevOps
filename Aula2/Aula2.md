Resumo da Aula 2 — CI/CD e Hospedagem

Na aula 2, aprofundamos nossos conhecimentos sobre CI/CD, entendendo o que esses conceitos significam, qual é a sua importância no desenvolvimento de software e como eles podem ser aplicados na prática.

Primeiramente, revisamos o conceito de CI (Continuous Integration), ou Integração Contínua. A ideia principal é integrar as alterações feitas no código de forma frequente em um repositório compartilhado. Dessa maneira, é possível identificar problemas e conflitos mais rapidamente, além de facilitar a realização de testes e validações automáticas sempre que uma nova alteração é enviada para o projeto.

Também estudamos o conceito de CD (Continuous Delivery/Continuous Deployment), que está relacionado à entrega e à implantação contínua da aplicação. Na prática, isso permite que, depois que o código é atualizado e validado, ele possa ser disponibilizado de forma automatizada para os usuários, reduzindo a necessidade de realizar todo o processo de publicação manualmente.

Depois da parte teórica, colocamos esses conceitos em prática. Criamos um repositório em grupo, onde desenvolvemos e organizamos um projeto para entender melhor o funcionamento desse fluxo. O código foi enviado para o GitHub e, posteriormente, utilizamos a Vercel para realizar a hospedagem da aplicação. Dessa forma, conseguimos observar na prática como uma alteração feita no código pode ser enviada para o repositório e posteriormente refletida na aplicação hospedada.

Um dos projetos desenvolvidos durante a aula foi o Rolador de Status RPG, que utilizamos como exemplo para colocar em prática o processo de versionamento, compartilhamento do código e hospedagem. O repositório pode ser acessado em https://github.com/LuisGlauser/RoladorDeStatusRPG.

Além desse projeto, também criamos um repositório específico para o nosso grupo, que será utilizado durante o restante do semestre. Esse repositório será o espaço principal onde iremos desenvolver e organizar o nosso projeto maior de DevOps, permitindo que todos os integrantes trabalhem em conjunto, façam alterações, acompanhem o histórico do código e utilizem os conceitos de CI/CD aprendidos ao longo das aulas.

O repositório do projeto do grupo é [LuisGlauser/DevOps_GrupoGeek](https://github.com/LuisGlauser/DevOps_GrupoGeek). A ideia é continuar utilizando esse ambiente durante o semestre para desenvolver o projeto principal, aplicando na prática os conceitos de Git, GitHub, CI/CD, integração, deploy e hospedagem.

Com a aula, foi possível perceber que CI/CD não é apenas um conceito teórico, mas uma metodologia que pode ser aplicada diretamente no desenvolvimento de projetos. Ao utilizar GitHub e Vercel, conseguimos visualizar todo o fluxo desde a criação e alteração do código até a sua disponibilização em uma aplicação acessível pela internet.
